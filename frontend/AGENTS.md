# Keep learning and nobody explodes

## Committing

- follow conventional commits: https://www.conventionalcommits.org/en/v1.0.0/

## Design

- Aim for low-poly

## Structure

- Islands (/islands) = one island per learning group, lined up left to right and joined by bridges
- Learning group = the user alone, or the user with one friend; users only see islands of their own groups (enforced by the backend)
- Each island has a grid of cells for houses; the same house design can stand on several islands at different levels
- Houses = Topics (Math, Endlish, Biology, Computer Science, etc.); a house's level on an island = how many of its storeys are built there
- Storeys = Key concepts of topics (build on each other. At fist only the first storey is available. User has to learn concepts to build a new storey. Storeys represent the concepts that depend on each other.)
